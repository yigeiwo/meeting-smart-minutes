      模式 A：Stream 模式长连接 (推荐 · 无需公网 IP / 穿透域名)

      原理：钉钉开放平台应用的 Client ID（原 AppKey）与 Client Secret（原 AppSecret）。适配器使用 Stream WebSocket 模式，不需要公网回调地址，内网机器直接建立长连接双向收发！

      获取方式：登录 钉钉开放平台 ➔【应用开发】➔【企业内部开发】➔ 创建应用 ➔ 获取 Client ID 和 Client Secret ➔ 在【机器人】菜单中启用机器人能力并选择 Stream 模式；

      调试日志：在配置中勾选【开启钉钉调试日志】，可在控制台实时查看与钉钉 Stream 网关的 WebSocket 握手报文与心跳 Ping/Pong。

      模式 B：群自定义 Webhook (单向群广播)

      定位：仅用于会议总结完成后向钉钉群单向推送 Markdown 纪要。

      获取：钉钉群 ➔ 智能群助手 ➔ 添加自定义机器人 ➔ 获取 Webhook URL 与加签 Secret (SECxxxxxxxx)。

      • 单向推送：群设置 ➔ 添加群机器人 ➔ 获取 Webhook URL，支持 mentioned_list (@成员) 与 mentioned_mobile_list (@手机号)；
      • 自建应用推送与回调：在企业微信管理后台创建自建应用，配置 CorpID、AgentID 与 AppSecret，支持企业全员或部门精准下发。

      模式 A：OneBot 反向 WebSocket 长连接 (推荐·零公网双向直连)

      原理：在 NapCat / Lagrange / Go-CQHTTP 配置文件中，添加反向 WebSocket 地址：

      "websocket": [{"type": "reverse", "url": "ws://127.0.0.1:8000/ws/onebot"}]

      NapCat 会主动向本系统发起长连接，群聊消息即时推入，系统自动回复，免公网 IP、免端口转发。

      模式 B：OneBot 正向 HTTP API + Webhook 上报

      国内反代网关与代理：可自定义 API Base 网关地址或填入本地 HTTP 代理（如 127.0.0.1:7890），解决境内网络环境访问问题。

      获取方式：进入 Discord 服务器 ➔ 频道设置 ➔【整合】➔【Webhooks】➔【创建 Webhook】➔ 复制 Webhook URL；

      4. AI Passport (ESP32-C3) 智能硬件胸卡配网与联调

      重置 Wi-Fi 无线配置
      • 物理按键重置：开机状态下长按【OK 键】5~8 秒，屏幕提示 Resetting Wi-Fi... 后自动进入 AP 配网模式；
      • 组合开机：关机状态下按住【OK 键】不放，同时长按【电源键】开机；
      • 串口重置：连接 Type-C 串口发送 reset_wifi。

      6. 本地运行内网穿透与外网 Webhook 回调指引

      如果您是在个人电脑本地开发，钉钉、飞书等公网平台无法直连 127.0.0.1，可使用免费穿透工具将本地 8000 端口映射到公网：

      # 方式 2：使用 ngrok 穿透
