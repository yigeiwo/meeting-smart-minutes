🎴 AI Passport 固件烧录

支持 Chrome / Edge 浏览器通过 WebUSB 直接免驱动烧录至硬件卡片

目标芯片： ESP32-C3 (8MB Flash)
合并镜像： FoloToy-AI-Passport-full.bin
烧录基地址： 0x000000
⚠️ 烧录准备：
  1. 用 Type-C 数据线将 AI Passport 胸卡连接至电脑 USB 接口；
  2. 推荐使用 Google Chrome 或 Microsoft Edge 浏览器；
  3. 点击下方蓝色按钮 ➔ 选中弹出的串口 ➔ 自动完成写入！
当前浏览器不支持 WebUSB 串口功能，请使用 Google Chrome 或 Edge 浏览器打开此网页，或运行同目录下的 flash_one_click.bat 批处理工具！
